# Public Roadmap

This is a directional roadmap, not a delivery guarantee. Priorities can change based on reliability, browser compatibility, privacy requirements, and user feedback.

## Shipped

- Image to PDF
- ZIP images to PDF
- PDF to PNG, JPG, and WebP
- PDF to TXT
- PDF to Markdown
- Markdown to PDF
- TXT to PDF
- HTML to PDF
- Merge PDF
- Extract PDF Pages
- Rotate PDF
- Resize PDF Pages
- PDF metadata inspection and cleanup
- PDF page rendering and embedded-image count reports

## Next

- Improved page reordering workflows
- Better output previews and verification reports
- Additional image and document conversion formats
- More page organization controls
- More PDF cleanup tools

## Exploring

- OCR and searchable PDF creation
- Scanned PDF cleanup
- Layout analysis
- Table detection and extraction
- Barcode and QR code detection
- Sensitive-information detection
- PDF quality checks
- PDF/A and PDF/UA checks
- Web optimization workflows
- Developer-focused exports and structured extraction

## Feedback

Share workflow requests or reproducible issues through [GitHub Issues](../../issues).
