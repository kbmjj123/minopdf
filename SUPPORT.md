# Support

## Product Help

For help using MinoPDF, visit:

- Website: [minopdf.com](https://minopdf.com)
- Tool directory: [MinoPDF tools](https://minopdf.com)

## GitHub Issues

Use GitHub issues for:

- Reproducible tool problems
- Broken pages or incorrect documentation
- Browser compatibility feedback
- Feature requests
- Feedback about supported formats or output quality

Before opening an issue, check whether the problem can be reproduced with a non-sensitive sample file.

## Do Not Post Sensitive Files

GitHub issues are public.

Do not attach or paste:

- Personal documents
- Identity documents
- Financial records
- Medical records
- Confidential contracts
- Password-protected files with passwords
- Private API keys, tokens, or credentials

If your issue involves a possible security or privacy problem, see [SECURITY.md](SECURITY.md) instead.

## Feature Requests

When requesting a feature, include:

- The task you are trying to complete
- The source file type and desired output
- Whether you need browser-only processing
- The expected result
- Any workflow or compatibility constraints
