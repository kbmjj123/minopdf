# Contributing

Thanks for your interest in MinoPDF.

MinoPDF is a proprietary product, and the application source code is not open for external pull requests.

However, feedback is welcome.

## You Can Help By

- Reporting reproducible bugs
- Suggesting useful PDF workflows
- Reporting inaccurate documentation
- Sharing browser compatibility observations
- Identifying unclear privacy or limitation wording
- Suggesting accessibility improvements

## Before Opening an Issue

- Check whether the issue has already been reported.
- Use a non-sensitive sample file whenever possible.
- Include the tool URL, browser, operating system, and steps to reproduce.
- Do not upload confidential documents or credentials.

For security concerns, follow the private reporting process in [SECURITY.md](SECURITY.md).
