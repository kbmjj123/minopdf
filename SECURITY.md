# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you found a security issue involving MinoPDF, file processing, privacy behavior, data handling, or the website, contact us privately:

- Security contact: security@minopdf.com

Please include:

- A clear description of the issue
- Steps to reproduce it
- The affected tool or page URL
- Browser and operating system details
- Screenshots or a safe, non-sensitive sample when possible
- Potential impact

Do not send passwords, private keys, confidential PDFs, personal data, or production credentials.

## Scope

Examples that may be in scope include:

- Unexpected file upload or network transmission
- Cross-site scripting or injection issues
- Data exposure across sessions
- Unsafe handling of user-provided documents
- Security issues in public-facing web pages
- Incorrect privacy disclosures

## Response

We will review reports as quickly as practical. Please allow reasonable time for investigation and remediation before public disclosure.
